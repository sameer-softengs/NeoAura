# NeoAura

NeoAura is an application project organized around a source directory, reusable libraries, and generated output artifacts.

## Project Structure

- `src/` — primary application source
- `libs/` — reusable libraries and supporting modules
- `out/` — generated or build output

## Getting Started

```bash
git clone https://github.com/sameer-softengs/NeoAura.git
cd NeoAura
```

Review the source and library configuration to identify the project’s required runtime and build commands. Keep generated output separate from source changes.

## Development Guidelines

- Keep reusable functionality in `libs/`.
- Keep application changes organized under `src/`.
- Do not commit secrets or unnecessary generated artifacts.
- Document new setup requirements and user-facing behavior.

## Status

This project is under active development. APIs and implementation details may evolve as features are refined.
